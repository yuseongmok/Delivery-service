# 다음 챕터 감옥 씬

## 열기
`Scenes/PrisonChapter.unity`를 연다. 기존 씬 및 Build Settings는 변경하지 않았다.
Synty와 Fonts는 프로젝트에 이미 있는 원본 파일을 참조한다. 이 폴더 전체와 .meta를 함께 커밋한다.

## 공간
- 약 110 × 92m의 교정시설 부지, 4개 감시탑과 외벽
- 중앙 2층 수감동: 24개 감방, 이층침대, 열린 철창문, 양끝 계단과 상층 난간
- 동쪽 식당/주방: 식탁, 조리대, 식재료와 배식 공간
- 서쪽 간수실/면회실/의무실
- 북쪽 운동장: 농구 코트, 휴식 벤치, 운동 기구
- 북동쪽 작업장/창고
- 주방 뒤 정비 통로와 외곽 반출 지점

모든 정적 공간과 소품은 씬에 저장되어 Play 전에도 편집할 수 있다.
Synty 메시와 텍스처를 이용하며, 재질은 이 폴더에 전용 복사본을 만들었다. Synty 원본 재질을 수정하지 않는다.

## 현재 플레이
`Assets/Scenes/PrisonChapter.unity`를 열고 Play하면 첫 임무가 시작된다.
밥 3인분 조리 → 카트에 싣기 → 재소자 3명에게 배식 → 의무실 잠입 → 민기와 대화 → 자기 방 복귀.
대사는 `Mission01/첫 임무 대사.asset`에서 수정한다.

## 도시와 공유하는 기능
도시의 PlayerMove, CameraMove, 전투·자세·상호작용, 휴대폰 Canvas와 앱, SettingsCanvas의 ESC 메뉴를 사용한다.
ESC 설정의 마우스 감도 슬라이더(25~300%, 기본 100%)를 도시와 감옥에서 공유한다. 닫을 때 저장되며 씬 전환과 재실행 후에도 유지된다.
목표는 공용 주황 마름모와 경로 재계산으로 안내한다. 지도에서는 현재 임무, 주방, 의무실, 내 방, 배식카트를 선택한다.
시간·일차·영업 주문 UI만 숨긴다. 휴대폰의 미션/문자는 감옥 진행을 표시한다.
오토바이 호출처럼 실제 대상이 필요한 기능은 감옥에 그 대상이 없으면 사용할 수 없다.

## 개발 주의
`PrisonSharedPresentation`은 감옥 상태를 공용 UI에 연결한다. `Prison common HUD`는 임무 루트와 별도 오브젝트여야 한다.
임무 루트에 Canvas를 추가하면 자식 조리대·배식 대상 좌표가 변하므로 합치지 않는다.
`PrisonCommonSetup`은 도시 씬을 읽어서 감옥에 공용 UI를 연결하고 감옥 씬만 저장한다.
기존 PreviewPlayer와 옛 PrisonMissionHUD/PrisonPhoneNotes는 실제 플레이에 사용하지 않는다.

생활동 죄수 50명과 간수 20명을 유지한다. 간수 16명은 배식 동선을 피한 고정 위치에서 주변을 살피고, 4명만 순찰한다. 죄수 속도는 1.5~1.85m/s, 간수는 1.65~1.95m/s이며 배식 대상과 감방 재소자는 별도로 유지한다. 순찰 NPC가 사망하면 사망 후 최소 8초, 기존 몸이 사라진 뒤 시야 밖 12m 이상 떨어진 빈 지점에서 보충한다. 안전한 장소가 없으면 기다린다. 감옥 생활 인원 오브젝트의 PrisonPopulation에서 리스폰 지연을 조절할 수 있다.

군중 이동은 가까운 생활 구역의 목적지를 예약해 분산한다. AI 판단은 0.2초마다 시간차를 두고 실행하며, 새 경로 요청은 프레임당 최대 2건이다. 카트를 미는 동안 전방의 순찰 NPC는 이동 가능한 옆 공간으로 비켜선다. 벽이나 NPC 충돌을 끄거나 순간이동시키지 않는다. 리스폰된 고정 간수도 자신의 경계 위치로 돌아간다.
