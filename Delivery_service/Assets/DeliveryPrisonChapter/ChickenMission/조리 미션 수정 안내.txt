갓 튀긴 치킨 — 감옥 미션 수정 안내

실행
Assets/Scenes/PrisonChapter.unity를 재생합니다.
머그샷 → 같은 방 대화 → 운동장의 최형욱 정보거래가 끝나면 치킨 미션이 시작됩니다.
도시의 일차/영업 조건은 사용하지 않습니다.

진행
1. 주황색 목적지 안내를 따라 주방 안내판에 F로 상호작용합니다.
2. 생닭, 밀가루, 올리브유, 물, 양념소스를 F로 모읍니다.
3. 치킨 조리대에 F로 상호작용합니다.
4. 닭 위 표시 클릭 → 밀가루/물 계량(좌클릭 누르기) → 마우스로 원 그리기 → 기름 계량 → 180도에 클릭 → 초록 구간에서 Space로 3회 뒤집기 → 소스 클릭.
5. F로 조리대에서 나갔다가 돌아와 이어서 조리할 수 있습니다.
6. 계량 초과 시 해당 재료만 다시 가져옵니다.
7. 치킨을 가지고 운동장으로 돌아가 죄수 2명을 제압합니다.
8. 최형욱 가까이에서 F를 눌러 치킨을 전달합니다. 대화 중 Space로 다음 대사로 넘깁니다.

실패
주방 제한시간 기본 360초. 메뉴에서 일시정지하면 제한시간도 멈춥니다.
바닥 조리도구 접촉, 기름 미끄러짐, 튀김 타이밍 실패는 소음을 만듭니다.
소음 3회 또는 시간 초과 시 주방장 연출 뒤 주방에서 다시 시작합니다.
치킨을 빼앗으려는 죄수에게 3회 맞아도 주방부터 다시 시작합니다.
재시작 시 재료, 소음, 조리 단계와 적이 초기화됩니다.

대사와 제한시간 수정
같은 폴더의 '갓 튀긴 치킨 대사와 시간.asset'을 선택하고 Inspector에서 수정합니다.
Start / Caught / Ambush / Defeated / Cooked / Fight Cleared: 상황 대사.
Delivery: 최형욱과의 마지막 대화. 위에서부터 한 줄씩 진행합니다.
Kitchen Seconds: 제한시간. Line Seconds: 자동 대사 진행 간격.

역할별 코드
PrisonChickenMission: 순서, 재료 보유, 실패/재시작, 대화.
ChickenCooking: 마우스/키보드 조리 판정.
ChickenCookingVisuals: 칼과 닭, 반죽/튀김 위치와 색상.
ChickenInteraction / ChickenNoiseHazard: 상호작용과 바닥 위험.
ChickenAmbusher: 치킨을 노리는 죄수의 추격과 근접 공격.
PrisonSharedPresentation / PrisonPhoneNotes: 공용 목적지 안내와 휴대폰 기록 연결.

검증 범위
Unity 플레이 모드에서 실제 입력 이벤트로 모든 조리 단계와 계량 초과 후 재수집을 검증했습니다.
소음/시간 초과 재시작, 전투 이후 전달, 대화 종료 후 조작 복구를 검증했습니다.
이동은 경로 연결 검사와 지정 위치 이동을 사용했습니다. 전 구간을 사람이 걸어서 플레이한 검사는 아닙니다.
도시 씬 및 Min/Wong/Woong/Yun 코드는 수정하지 않았습니다.
