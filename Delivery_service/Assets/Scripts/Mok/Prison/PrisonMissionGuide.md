# 감옥 첫 임무: 민기를 찾아서

## 실행과 대사 수정
- 씬: `Assets/Scenes/PrisonChapter.unity`
- 대사: `Assets/DeliveryPrisonChapter/Mission01/첫 임무 대사.asset`
- Inspector에서 도입, 세 재소자 대화, 민기 대화, 발각/공격 실패, 완료 문구와 목표를 수정한다.
- 현재 제작 범위는 첫 임무까지다. 완료 후 감옥을 계속 둘러볼 수 있으며 다음 임무는 아직 연결하지 않는다.

## 진행
1. 주방의 냄비를 바라보고 F로 3인분을 준비한다.
2. 카트 본체에 F로 식사를 싣는다. 손잡이 또는 본체에서 F로 밀기/놓기를 전환한다.
3. 주황 마름모가 표시하는 세 재소자에게 카트를 가져가 F로 전달한다. 카트가 4.5m 안에 있어야 한다.
4. 세 번째 재소자가 민기의 의무실 위치를 알려준다.
5. 의무실 정문 앞 배관을 F로 두드려 간수를 20초 동안 유인할 수 있다. Ctrl 앉기와 구조물을 이용해 시선을 피한다.
6. 민기의 병상을 바라보고 F로 대화한다. 각 대사를 읽은 뒤 다시 F로 다음 대사로 넘어간다.
7. 자기 방의 목표에서 F로 임무를 끝낸다.

## 실패 규칙
- 의무실 제한 구역에서 간수 정면 시야에 1.5초 노출되면 발각된다. 벽에 가리면 감지되지 않는다.
- 잠입 실패는 배식 완료 상태를 유지하고 의무실 진입 전 위치부터 재시도한다.
- 간수를 공격하면 권총 반격과 암전 후 첫 임무 전체를 다시 시작한다. 식사, NPC, 카트도 초기 상태로 복원한다.
- 플레이어와 민기의 지정 감방에는 다른 재소자를 배치하지 않았다.

## 기존 기능 연결
- 도시 Player를 복제해 이동, 달리기, 점프, 앉기, Q/E 기울이기, 주먹, 무기 사용 및 플레이어 래그돌 구성은 유지했다.
- 감옥 시작 무기는 없음. 도시의 차량 호출과 도시용 월드 참조는 연결하지 않는다.
- M으로 같은 휴대폰을 꺼내 현재 목표/알아낸 정보를 확인한다. 위/아래로 선택한다. 감옥 전용 화면이며 도시 금융·지도 앱을 이식한 것은 아니다.
- 배식카트 이동은 Woong의 FoodCartController를 재사용한다. 음식 수량과 전달 연출만 PrisonMealCart가 담당한다.
- 수감자 모델은 Synty Prisoner, 간수는 Synty Police를 사용한다. 기존 NPC 리그와 래그돌은 유지하고 전체 의상 파츠를 연결했다.

## 코드 역할
- PrisonMission: 단계 전환, 조리/대화 순서, 재시도
- PrisonMissionPoint: F 상호작용 전달
- PrisonMealCart: 3인분 적재, 식판 전달 표시
- PrisonGuard: 순찰, 시야·의심도, 공격 반격
- PrisonDistraction: 배관 소리 유인
- PrisonResident: 지정 구역 이동과 시민 전투 제어 전환
- PrisonMissionHUD / PrisonPhoneNotes: 목표·자막·휴대폰 기록
- PrisonAudio: 기존 실내·금속 효과음 재사용
- Editor/PrisonMissionBuilder: 최초 배치 전용. 이미 배치된 씬을 덮어쓰지 않는다.
- Editor/PrisonMissionPolish: 첫 배치 보완. 실제 배치는 씬에 저장되어 Play 전에도 확인된다.
- Editor/PrisonMissionCheck: 임무 연결 및 재시작 Play Mode 검사. 이동 위치와 상호작용 호출은 검사 코드가 준비하므로 수동 전체 플레이와 구분한다.

## 일차 시스템 제거
- 도시와 감옥에서 DAY/시계 및 개점·마감·다음 날 정산 진행을 사용하지 않는다.
- DayNightCycle의 타입과 필드는 기존 씬 참조 호환을 위해 남아 있다. 자동 시간 진행, 날짜 증가, 일일 이자/임대료/파산 정산 호출은 제거했다.
- 조명에 사용하는 시각 값은 유지한다. 미션 준비 상태는 튜토리얼 완료 여부로 판단한다.
- 다음 스토리 임무는 이전 임무 완료 후 해금된다. 피날레는 다음 날 전환을 기다리지 않고 바로 시작한다.
- 구매 재료는 다음 날 대기 대신 바로 입고한다.
- 기존 소매치기, 주식, 강도의 영업 시간 의존 조건은 해제했다.
- 기존 재료·주문·자금 시스템 자체를 모두 삭제한 것은 아니다. 스토리에서 사용하는 기능과 튜토리얼은 유지한다.

## 팀원 파일 변경
- Woong/Scripts/Time/DayNightCycle.cs: 일차/정산 제거, 시간 UI 숨김, 재료 즉시 입고
- Min/NPC/RobberyManager.cs, RobberAI.cs: 영업 중 조건 제거. 강도 AI 및 전투 로직은 변경하지 않음
- 그 밖의 변경은 Mok 코드와 PrisonChapter 씬, 감옥 전용 에셋에 한정한다.

## 개발자 바로 이동
- Ctrl + Shift + F12 → `감옥 챕터 처음부터 시작` 선택 → Enter.
- 에디터와 일반 빌드에서 모두 사용한다. PrisonChapter는 빌드 씬 목록에 포함되어 있어야 한다.
- 기존 진행 중인 씬을 떠나 감옥 첫 임무를 초기 상태로 시작한다. 치트 무적도 해제한다.

## 배식카트 보완
- 바퀴 높이에 맞춘 충돌체와 낮은 문턱 통과 보정을 적용했다. 높은 벽/가구는 통과하지 않는다.
- 일반 배식카트 충돌은 간수 공격으로 처리하지 않는다. 주먹과 무기로 공격하는 규칙은 그대로다.
- 배식/놓기 시 플레이어와 겹친 카트의 충돌은 떨어진 뒤 복구한다.
- 손잡이와 본체는 동일한 적재·밀기·놓기 처리를 사용한다.
- 도시 공용 FoodCartController는 변경하지 않았다.

## 연속 동선 확인 (2026-11-11)
- Unity Play Mode에서 실제 CharacterController/Rigidbody 충돌 이동과 F 입력을 사용한 자동 주행 검사로 조리 → 적재 → 3명 배식 → 배관 유인 → 의무실 대화 → 재유인 → 방 복귀 완료를 확인했다.
- 위치 순간이동이나 임무 단계 변경 없이 완료했다. 전 구간을 사람이 키보드로 직접 조작한 검사는 아니다.
- 의무실 입구와 병상 옆 배관은 F로 사용하며 간수를 20초 동안 유인한다. 대화가 끝나면 병상 옆 배관을 활용해 돌아갈 수 있다.
- 빌드 실행 검사는 별도로 하지 않았다.
