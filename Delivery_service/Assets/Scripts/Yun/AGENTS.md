# Yun 작업 원칙

- 코드 생성 및 변경은 Yun 폴더 안에서 진행한다. 다른 기여자의 코드는 기존 스타일과 연동 방식 확인을 위해 읽을 수 있다.
- 기능마다 메인 관리 스크립트를 두고 관련 항목을 통합한다. 항목이 추가될 때마다 관리 스크립트를 새로 만들지 않는다.
- 효과음의 게임 상태 연결은 Audio/GameplayAudio.cs에 추가하고, 음원과 설정은 SoundLibrary에서 관리한다. AudioManager는 공통 재생 기능을 담당한다.
- 별도 스크립트 분리가 반드시 필요한 경우에는 작업 전에 사용자에게 이유와 범위를 설명한다.
- UI는 실행 시 코드로 일괄 생성하지 않고 Canvas에 저장된 오브젝트로 구성한다.
